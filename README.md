# Lonewolf Nightvision VR

Versión corregida basada en el repositorio VISION-NOCTURNA-VR.

Cambios de esta versión:
- Retícula VR corregida para que aparezca correctamente en ambos ojos.
- La retícula y la escala usan un sistema de coordenadas independiente por ojo.
- Se conserva el zoom inicial en **0.9×**.
- Se conservan cámara trasera, modos de visión, brillo, contraste, ganancia, retícula, escala, medición tangencial, brújula, orientación horizontal y VR Box.
- Service Worker versionado para forzar actualización de archivos modificados.
