# Lonewolf Nightvision VR

Versión actualizada del visor offline.

Cambios de esta versión:
- Zoom inicial: **0.9×** y rango ajustado desde 0.9×.
- Se conservan cámara trasera, modos de visión, brillo, contraste, ganancia, retícula, escala, medición tangencial, brújula, orientación horizontal y VR Box.
- En modo VR, el video se divide en dos ojos y el HUD visual se duplica para cada ojo.
- Retícula y escala también se dibujan por ojo en VR.
- Service Worker actualizado para evitar que el navegador conserve la versión anterior.

Uso: abrir `index.html` mediante GitHub Pages/servidor HTTPS o instalación PWA. La cámara requiere un contexto seguro.
